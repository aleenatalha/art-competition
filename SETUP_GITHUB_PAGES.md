# GitHub Pages Setup Instructions

## Quick Setup (2 minutes)

1. **Go to your repository on GitHub:**
   ```
   https://github.com/aleenatalha/art-competition
   ```

2. **Click on "Settings"** (top right of repository page)

3. **Click on "Pages"** (in the left sidebar under "Code and automation")

4. **Under "Source":**
   - Select branch: `claude/art-competition-booking-app-JtLI0`
   - Select folder: `/ (root)`
   - Click **Save**

5. **Wait 1-2 minutes** for GitHub to build your site

6. **Your app will be live at:**
   ```
   https://aleenatalha.github.io/art-competition/
   ```

7. **Refresh the Settings > Pages** page to see the green checkmark when it's ready!

---

## Troubleshooting

**If you see "404" after setup:**
- Wait another minute and refresh
- Clear your browser cache
- Try the link in an incognito/private window

**If GitHub Pages option is not available:**
- Make sure the repository is public (Settings > General > Danger Zone)
- Or use the download method instead

---

## Alternative: Direct Download

If you prefer not to use GitHub Pages:

1. Download `index.html` from the repository
2. Double-click to open in your browser
3. Works offline, no internet needed after download!
